# IngressosFácil — Formulário de cadastro com JavaScript

Atividade extra da Aula 14 (Manipulação do DOM) — Desenvolvimento Front-End para Web, Unifran.

## O que a página faz

- Formulário de cadastro (nome, e-mail, senha, categoria e termos de uso) estilizado com Bootstrap 5
- Envio tratado por JavaScript com `preventDefault()`, sem recarregar a página
- Validação campo a campo, com mensagem de erro ao lado de cada campo
- Dados lidos dos campos e agrupados em um objeto
- Alerta verde na tela com nome, e-mail e categoria — a senha não é exibida
- Formulário limpo depois do cadastro

## Arquivos

- `index.html` — a página de cadastro
